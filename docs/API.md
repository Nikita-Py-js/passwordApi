# API

- **Base URL:** `https://your-domain.example`
- **Формат:** JSON
- **Кодировка:** UTF-8
- **Авторизация:** заголовок `X-Api-Key`
- **Транспорт:** только HTTPS

## POST /Api.ashx — создать ссылку

### Заголовки

| Заголовок | Обязателен | Значение |
|---|---|---|
| `X-Api-Key` | Да | Ваш API-ключ |
| `Content-Type` | Да | `application/json` или `application/x-www-form-urlencoded` |

### Тело (JSON)

```json
{
  "secret": "P@ssw0rd!",
  "ttl": 60,
  "u": "test",
  "d": "16.10.2026 09:59"
}
```

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `secret` | string | да | Пароль. Макс. `MaxSecretSize` символов |
| `ttl` | int | нет | TTL в минутах. Дефолт `DefaultTtlMinutes`, максимум `MaxTtlMinutes` |
| `u` | string | нет | Логин — отображается на странице просмотра |
| `d` | string | нет | Дата смены — отображается на странице просмотра |

### Ответ 200

```json
{
  "url": "https://.../View.ashx?id=0fdca...&u=test&d=16.10.2026",
  "id": "0fdca0c656044f0291a673ebcfad8821",
  "expiresMinutes": 60,
  "expiresAtUtc": "2026-10-16T12:34:56.789Z"
}
```

| Поле | Описание |
|---|---|
| `url` | Готовая ссылка для получателя |
| `id` | GUID секрета (32 hex-символа) |
| `expiresMinutes` | Фактически применённый TTL |
| `expiresAtUtc` | Момент истечения в UTC, ISO 8601 |

### Ошибки

| Код | Тело | Причина |
|---|---|---|
| 400 | `{"error":"Поле secret обязательно"}` | Нет `secret` |
| 400 | `{"error":"Слишком большой секрет"}` | `secret` длиннее `MaxSecretSize` |
| 400 | `{"error":"Некорректный JSON"}` | Не удалось распарсить тело |
| 401 | `{"error":"Неверный API-ключ"}` | Ключ отсутствует или не совпадает |
| 401 | `{"error":"IP не разрешён"}` | IP клиента не в `ApiAllowedIps` |
| 401 | `{"error":"ApiKey не задан в Web.config"}` | `ApiKey` пуст |
| 405 | `{"error":"Только POST"}` | Использован GET |

## GET /View.ashx?id=&lt;guid&gt; — просмотр пароля

Открывается в браузере. Авторизация не требуется. Одноразовый просмотр: после первого успешного открытия файл секрета удаляется.

### Query-параметры

| Параметр | Обяз. | Описание |
|---|---|---|
| `id` | да | GUID секрета (32 hex-символа) |
| `u` | нет | Логин — отображается на странице |
| `d` | нет | Дата смены — отображается на странице |

### Ответы

| Код | Что |
|---|---|
| 200 | HTML-страница с паролем |
| 404 | HTML-страница «Ссылка недействительна» |

Этот эндпоинт **не предназначен для программных вызовов** — только браузер человека.

## Гарантии

- Секрет шифруется на диске (AES-256-CBC).
- Удаление после первого просмотра атомарно (`File.Move` как lock).
- Даже при гонке двух параллельных просмотров пароль получит только один.
- После TTL ссылка мертва независимо от того, была ли она просмотрена.
